# 採用ルールと監修手順

## 基準

- 内部ルールセットID: `mleague-2026-v1`
- 一次資料: [Mリーグ公式戦ルール](https://m-league.jp/about/)
- 参照日: 2026-09-05
- 対象: 四人打ちの和了形、役、符、翻、親子別のロン・ツモ支払い
- 問題条件として固定: 本場0本、供託0点
- 現在の対象外: 局進行、順位点、罰符、責任払い、複数役満、流局処理

Mリーグ公式戦ルールに合わせ、3翻60符と4翻30符は切り上げ満貫とする。連風牌の雀頭は2符とする。赤五萬・赤五筒・赤五索は各1枚で、それぞれドラ1翻として数えるが、赤ドラだけでは和了役にならない。

## 根拠の優先順位

1. Mリーグ公式戦ルール本文と公式点数表
2. Rule ownerが承認した本ドキュメントとgolden test
3. 雀カクのMリーグ点数表
4. 雀天のMリーグ点数表

既存サイト一つの結果を正解として採用しない。問題文・画像・牌素材も転載しない。資料間で不一致が出た場合は公開を止め、Rule ownerが一次資料に基づいて裁定し、ルールセットIDまたは問題revisionを更新する。

## 役割

### Rule owner

Mリーグ公式資料を読んで適用範囲を決定し、ルールセットを版管理する責任者。初期運用では実装責任者が兼任できる。資料間の不一致、境界事例、問題報告が発生した場合は公開を止め、必要に応じて専門家へ相談する。

### Rule reviewer

常設の必須担当ではない。自動検証や資料照合で解消できない境界事例、異議、事故時に依頼する専門家とする。依頼する場合は、競技麻雀の審判経験者、プロ雀士、点数計算を日常的に教える上級者が適する。

## 問題の公開手順

1. 作者が牌姿、待ち、役、符の部品、翻、支払い、誤答根拠を記録する。
2. 自動検証で牌枚数、ドラ、符合計、点数表、選択肢重複を検査する。
3. Mリーグ公式資料、雀カク、雀天に対するURL・確認日・一致結果を記録する。
4. 自動検査7項目がすべて揃った問題だけ`reviewed`にする。
5. Rule ownerがルール境界問題と資料差分を承認する。
6. 類題バランスと表示確認後に限り`published`にする。

現在の15問には完全な手牌分解、ScoringBasis、必須自動検査7項目、支払い表の外部照合証跡があり、`published`として本番出題できる。
