# ADR-004 自動検証と外部照合で問題を公開する

- Status: Accepted
- Date: 2026-09-05

## 決定

公開問題に人間の独立監修を必須としない。Mリーグ公式戦ルールを一次資料とし、完全な手牌分解・点数内訳に対する自動検証と、異なる外部資料2系統の点数照合が揃った問題を公開可能とする。

`reviewed`および`published`には、完全な`ScoringBasis`、手牌分解、必須自動検査、公式資料URL、外部資料2件以上のURL・確認日・一致結果を必要とする。外部資料は支払い表の照合であり、牌姿からの役判定を保証しない。そのため、完全内訳がない問題は照合記録があっても`draft`のままとする。

人間のRule reviewerは必須ロールから、境界事例・異議・事故時に依頼する任意の専門家へ変更する。Rule ownerは実装責任者が兼任できる。

## 安全策

- 自動検証または外部照合が一つでも欠けた問題は公開しない。
- 外部照合先は同一URLを重複登録できない。
- 各問題にID・revision・rulesetを含む問題報告リンクを表示する。
- 誤りが確認された問題は`retired`へ変更し、即時再デプロイする。
- 「人間監修済み」と表示しない。

本ADRは、既存文書に残る「人間の独立監修・二重監修を必須とする」という記述を上書きする。
