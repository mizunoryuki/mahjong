# この手、何点？

5問の実戦形式で、麻雀の点数計算で現在引っかかっている箇所を確認するWebアプリです。

利用者は毎回、和了時の最終的な支払いを4択で回答します。誤答した場合だけ飜数・符数を追加で確認し、`han`、`fu`、`payout`のどこでつまずいた可能性があるかを切り分けます。同じセッション内で類題を出し、その場で理解できたかも確認します。

## MVPの方針

- 四人打ちリーチ麻雀、本場なし
- 1セッション5問
- ログイン、アカウント、サーバー保存なし
- タイマー、ランキング、ストリークなし
- 監修済みの問題バンクを使用
- 決定論的な採点・診断
- スマートフォンを中心に、キーボードとスクリーンリーダーにも対応

## 開発計画

最初の到達点は、15〜20問を使った診断プロトタイプです。対象利用者テストに合格した後で、64問の公開βへ展開します。

React、TypeScript、Viteで実装し、Cloudflare Workers Static Assetsへ配信します。`main`にはMilestone 0と点数支払いの基盤、未マージのPR #20には問題検証と5問セッションのdomain基盤があります。

詳細な仕様、状態遷移、問題データ、診断ロジック、品質基準は[プロダクト・技術設計書](docs/product-design.md)を参照してください。

別の開発者やAIが作業を再開する場合は、[開発引き継ぎ書](docs/handoff.md)から確認してください。現在の実装範囲、未完了Issue、推奨順序、開発・監修・本番運用体制をまとめています。

## 開発環境

```sh
npm ci
npm run dev
```

```sh
npm run check
npm run test:e2e
npm run deploy:dry-run
```

チケット、リポジトリ運用、CI/CD、テスト方針は`docs/`にまとめています。
