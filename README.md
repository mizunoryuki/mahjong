# この手、何点？

5問の実戦形式で、麻雀の点数計算で現在引っかかっている箇所を確認するWebアプリです。

利用者は毎回、和了時の最終的な支払いを4択で回答します。誤答した場合だけ飜数・符数を追加で確認し、`han`、`fu`、`payout`のどこでつまずいた可能性があるかを切り分けます。同じセッション内で類題を出し、その場で理解できたかも確認します。

## MVPの方針

- 四人打ちリーチ麻雀、本場なし
- 1セッション5問
- ログイン、アカウント、サーバー保存なし
- タイマー、ランキング、ストリークなし
- 監修済みの問題バンクを使用
- 決定論的な採点・診断
- スマートフォンを中心に、キーボードとスクリーンリーダーにも対応

## 開発計画

最初の到達点は、15〜20問を使った診断プロトタイプです。対象利用者テストに合格した後で、64問の公開βへ展開します。

現在は設計段階で、アプリケーションコードはまだありません。実装はReact、TypeScript、Vite、Cloudflare Workers Static Assetsを予定しています。

詳細な仕様、状態遷移、問題データ、診断ロジック、品質基準は[プロダクト・技術設計書](docs/product-design.md)を参照してください。
